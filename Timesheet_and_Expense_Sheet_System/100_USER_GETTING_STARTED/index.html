    Getting Started for Users

    Introduction and Navigation

    Users can access the timesheet and expense sheet system using the Employee Portal button in the navigation bar on the inventory system dashboard page, or the /project1 route.

    From the Dashboard Hub, users can see basic statistics on their total pending and rejected submissions.

    Under Quick Actions, users can access the pages to view and submit their timesheets and expense sheets.

    Timesheets

    From the Timesheet page, users can access their controls for managing and viewing their timesheet submissions.

    Under the different tab pages, users can create a New Sheet, View Draft, View Pending, View Rejected, and View Approved.

    New Sheet

    In the New Sheet tab, users submit their timesheet submissions.

    Users can save their current timesheet submission as a draft with the Save as Draft button, and can submit their current timesheet as a pending submission for an administrator to review with the Submit Time Sheet button.

    When the user attempts to save as a draft or submit to an administrator for review, the timesheet submission must first be valid, so every added row must have all required fields entered.

    When a timesheet is successfully saved as a draft, the tab will be switched to the View Draft tab and set the newly created timesheet as the currently selected timesheet. When a timesheet is successfully submitted for review, the tab will be switched to the View Pending tab and set the newly created timesheet as the currently selected timesheet.

    Users can add multiple rows to a timesheet with the Add Row button. There is no limit for how many rows may be added to a timesheet.

    A row represents a continuous time frame, so timesheets may contain multiple rows with the same date (ex. the user enters a row for their working hours before their lunch break, and another row for their working hours after their lunch break).

    Users can remove a row using the red button with the trash-can icon at the end of the row.

    Required Fields

    Timesheet Supervisor

    The Timesheet Supervisor is the administrator that the user will request to review their timesheet, and must be a user with valid administrator permissions.

    The Timesheet Supervisor is distinct from the Supervisor field, and does not need to be the same administrator.

    Date

    The respective date of the timesheet row.

    Project

    The related project of the timesheet row. Projects are created by administrators, and have roles assigned to them.

    Role

    The related role of the timesheet row. Roles are created by administrators, and are assigned under a project. Users must first select a Project before they can select a role.

    Supervisor

    The related supervisor of the timesheet row.

    The Supervisor is distinct from the Timesheet Supervisor field, and does not need to be the same administrator.

    Time In

    The respective start time of the timesheet row. When entered with a Time Out, the Hours will automatically be calculated.

    The Hours calculated by the range may not exceed 24 hours, so the user must create another row if they wish to log mo re than 24 hours for a time frame.

    Time Out

    The respective end time of the timesheet row. When entered with a Time In, the Hours will automatically be calculated.

    The Hours calculated by the range may not exceed 24 hours, so the user must create another row if they wish to log mo re than 24 hours for a time frame.

    Non-Billable

    Marks whether the timesheet row is a billable time frame.

    (Optional Fields)

    Description

    The user may add a description to a timesheet row to add clarifications and details, or leave a note for the administrator to read during review.

    Per Diem

    Marks whether the timesheet row is a daily allowance paid to employees to cover expenses incurred while traveling for work. Users can mark more than one per diem field in a timesheet row.

    The label markings are as follows:

    • B – Breakfast
    • L – Lunch
    • S – Supper
    • I – Incidentals

    View Draft

    The View Draft tab displays the user's existing timesheet drafts, and allows the user to search and select a timesheet draft to edit and update.

    Usage

    Clicking on a timesheet draft in the table opens a modal to view the timesheet draft details. The Select button in the modal selects the timesheet draft for editing. Clicking the View Draft tab will set the view back to displaying the user's timesheet drafts.

    The UI for editing the timesheet draft is the same as in the New Sheet tab.

    The Delete button will delete the currently selected timesheet draft.

    The Save Draft button will update the currently selected timesheet draft with the newly edited values.

    The Submit Draft will submit the current selected timesheet draft for review from the administrator, and change the current tab view to View Pending with the current timesheet as the selected timesheet.

    Search

    Timesheet drafts can be searched using their Timesheet ID if you happen to already know it, or their timestamp that they were created at.

    Timestamps are formatted as YYYY-MM-DDTHH:mm:ss.sssZ (etc. 2025-08-07T20:36:33.750Z), and search completion results may not show up until the YYYY-MM are entered into the search box (etc. 2025-08).

    View Pending

    The View Pending tab displays the user's pending timesheets for review from the administrator, and allows the user to search and select a pending timesheet to edit and update.

    Usage

    Clicking on a pending timesheet in the table opens a modal to view the pending timesheet details. The Select button in the modal selects the pending timesheet for editing. Clicking the View Draft tab will set the view back to displaying the user's pending timesheet.

    The UI for editing the pending timesheet is the same as in the New Sheet tab.

    The Delete button will delete the currently selected pending timesheet.

    The Save as Draft will remove the current selected pending timesheet from review and change it to a timesheet draft, and set the current tab view to View Draft with the current timesheet as the selected timesheet.

    The Update Submission button will update the currently selected pending timesheet with the newly edited values.

    Search

    Expense Sheets

    From the Expense Sheet page, users can access their controls for managing and viewing their expense sheet submissions.

    Under the different tab pages, users can create a New Sheet, View Draft, View Pending, View Rejected, and View Approved.

    New Sheet

    In the New Sheet tab, users submit their expense sheet submissions.

    Users can save their current expense sheet submission as a draft with the Save as Draft button, and can submit their current expense sheet as a pending submission for an administrator to review with the Submit Expense Sheet button.

    When the user attempts to save as a draft or submit to an administrator for review, the expense sheet submission must first be valid, so every added row must have all required fields entered.

    When a expense sheet is successfully saved as a draft, the tab will be switched to the View Draft tab and set the newly created expense sheet as the currently selected expense sheet. When a expense sheet is successfully submitted for review, the tab will be switched to the View Pending tab and set the newly created expense sheet as the currently selected expense sheet.

    Users can add multiple rows to a expense sheet with the Add Row button. There is no limit for how many rows may be added to a expense sheet.

    A row represents a single expense, so expense sheets may contain multiple rows with the same date.

    Users can remove a row using the red button with the trash-can icon at the end of the row.

    Required Fields

    Expense Supervisor

    The Expense Supervisor is the administrator that the user will request to review their expense sheet, and must be a user with valid administrator permissions.

    The Expense Supervisor is distinct from the Supervisor field, and does not need to be the same administrator.

    Date

    The respective date of the expense sheet row.

    Project

    The related project of the expense sheet row. Projects are created by administrators, and have roles assigned to them.

    Role

    The related role of the expense sheet row. Roles are created by administrators, and are assigned under a project. Users must first select a Project before they can select a role.

    Supervisor

    The related supervisor of the expense sheet row.

    The Supervisor is distinct from the Expense Supervisor field, and does not need to be the same administrator.

    Billable

    Marks whether the expense sheet row is a billable expense.

    Name

    The respective name of the expense.

    Payment Type

    The respective payment type of the expense.

    Expense Type

    The respective payment type of the expense. The Car Rental and Mileage expense types require extra fields.

    Car Rental

    The KM In and KM Out specify the kilometers into the journey and out made by the Rental Company.

    Mileage

    The KM In and KM Out specify the kilometers into the journey, and are used alongside the Rate to automatically compute and fill out the Amount field as amount = (km_out - km_in) * rate. The amount can still be manually entered in later.

    Amount

    The respective amount cost of the expense.

    (Optional Fields)

    Description

    The user may add a description to a expense sheet row to add clarifications and details, or leave a note for the administrator to read during review.

    Receipts

    The user may upload receipts or files as proof/evidence of their expense, if required by the administrator.

    Supported file types include:

    • pdf
    • jpg
    • png
    • docx
    • xlsx
    • txt
