    Inventory System

    Overview

    The AUAV Inventory System is used to manage purchase orders, inventory, vendor and customer contacts, and has features like a part number finder and cost calculation.

    • Login to view the dashboard

    Login Page

    Permissions

    The following are the different user permissions: Sales, Warehouse, Engineer, Buyer, Admin. These permissions will each have different access to the dashboard. Permissions can only be managed by Admin through the Admin Portal.

    Disable User

    • Disabled user will no longer be able to login and access inventory system
    Delete User

    • Deleted user will no longer be able to login and access inventory system
    • Cascade hard delete ON:
      • All logs related to this user will be deleted permanently
    • Cascade hard delete OFF:
      • All logs related to this user will be changed to ‘deleted user’

    Stocktacking Access

    • Stocktacking function is used monthly to update inventory item quantities to match actual quantities
    • Enabling stocktacking access allows users with warehouse permission to access stocktaking controls and start/end stocktaking operations
    • See 'Stocktacking Control' for more information

    • When stocktacking is active (function being used by Warehouse user), stocktacking access cannot be disabled by Warehouse Administration
